# Время в пути

Локальное React-приложение строит приблизительные зоны времени в пути от выбранной
точки или к ней. По умолчанию выбраны координаты Центрального телеграфа:
`55.758272, 37.611014`.

Вместо Яндекс Маршрутов приложение использует открытую карту OpenStreetMap и
локальный граф Московского метро. Поэтому один расчёт может обработать тысячи
точек без тысяч сетевых запросов и без случайного выбора автобуса вместо метро.

## Как считается маршрут

Для каждой ячейки сравниваются два варианта:

1. весь путь пешком;
2. пешком до станции → метро по кратчайшему пути → пешком от станции.

Граф строится из активных станций и связей `adjacent station (P197)` в Wikidata.
Кратчайшие пути от выбранной точки до всех станций находятся одним запуском
алгоритма Дейкстры, после чего тысячи ячеек рассчитываются полностью в браузере.

### Фактические источники

- карта: [OpenStreetMap](https://www.openstreetmap.org/copyright), данные ODbL;
- отображение карты: [MapLibre GL JS](https://maplibre.org/maplibre-gl-js/), BSD-3-Clause;
- станции, координаты, линии и соседние станции:
  [Wikidata Query Service](https://query.wikidata.org/), данные CC0;
- средняя скорость поездов с учётом остановок — 41 км/ч:
  [Московский метрополитен](https://mosmetro.ru/news/details/6701);
- базовая скорость ходьбы — 5 км/ч, как в открытом pedestrian-профиле
  [openrouteservice](https://giscience.github.io/openrouteservice/technical-details/travel-speeds/).

### Оценочные параметры

Публичного официального GTFS-расписания Москвы в проекте нет. Поэтому ожидание
поезда, вход/выход, пересадки и непрямолинейность пешего пути заданы прозрачными
константами в `src/lib/metro.ts` и `src/lib/geo.ts`. Это приближение, а не
расписание на конкретную минуту.

Направления «к точке» и «от точки» дают одинаковый результат: локальный граф не
учитывает расписание и временные односторонние ограничения.

## Возможности

- открытая карта без API-ключа;
- выбранная точка по умолчанию — Центральный телеграф;
- режимы «Метро + пешком» и «Только пешком»;
- интервалы heatmap по 3 минуты;
- 55 296, 163 840 или 368 640 локально рассчитанных ячеек;
- адаптивная панель для телефона;
- ноль маршрутных API-запросов при расчёте.

Автобусы, трамваи и «весь транспорт» сознательно убраны: без актуального открытого
GTFS они снова давали бы неподтверждённый способ поездки.

## Запуск

```bash
npm install
npm run dev
```

Откройте `http://localhost:5173`. Переменные окружения и ключи не нужны.

Стандартные тайлы OpenStreetMap подходят для локальной разработки и небольшого
трафика. Для публичного высоконагруженного размещения подключите собственного
тайл-провайдера согласно
[политике OSM](https://operations.osmfoundation.org/policies/tiles/).

## Обновление метро

В репозитории хранится готовый снимок данных, поэтому обычный запуск не зависит от
Wikidata. Чтобы обновить его:

```bash
npm run update:metro
```

Скрипт оставляет только уже открытые станции и исключает строящиеся линии.
